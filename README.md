# Sistema de Controle de Notas

Projeto desenvolvido em linguagem C para praticar conceitos básicos de programação.

## Funcionalidades

- Cadastro de alunos
- Cadastro de duas notas
- Cálculo da média
- Classificação em aprovado, recuperação ou reprovado
- Maior e menor média da turma
- Média geral da turma
- Contagem de alunos por situação

## Conceitos utilizados

- Vetores
- Strings
- Estruturas de repetição
- Estruturas condicionais
- Entrada e saída de dados
- Cálculos matemáticos
